# Global-Superstore-Business-Dashboard

Project Overview
This project focuses on analyzing the Global Superstore dataset using Power BI. The dashboard provides insights into sales performance, profitability, customer behavior, and regional trends.

## Tools Used
 Power BI
 Excel/CSV Dataset

## KPIs
- Total Sales: 12.64M
- Total Profit: 1.47M
- Total Orders: 25.03K
- Total Customers: 1.59K

## Dashboard Features
- Year-wise Sales Trend
- Profit by Sub-Category
- Sales by Region
- Global Sales Distribution Map
- Top 10 Customers Analysis
- Sales by Category
- Interactive Filters

## Key Insights
- Sales increased steadily from 2011 to 2014.
- Technology was the highest-selling category.
- Central region contributed the highest sales.
- Top customers generated significant revenue.

## Conclusion
The dashboard helps organizations monitor business performance and make data-driven decisions through interactive visualizations.
